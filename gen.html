# 星云 AI · 部署指南（国内零成本版） > 目标：让网页能真正生成图片，全程 0 元、不要信用卡、国内直连。 > 结构变了：以前是「GitHub Pages 前端 + Cloudflare Worker 后端」，现在后端搬到**阿里云函数计算 FC**。 > 原因：`*.workers.dev` 在国内网络被拦，浏览器根本连不上（`ERR_CONNECTION_TIMED_OUT`）。 --- ## 第 0 步：准备（一次性） 1. 阿里云账号**实名认证**（个人，身份证 + 支付宝/微信人脸）。函数计算不开实名用不了。 2. 智谱账号（手机号注册即可，不用实名、不用绑卡）。 --- ## 第 1 步：拿智谱的免费 API Key（约 5 分钟） 1. 打开 2. 右上角「注册 / 登录」，用手机号注册 3. 登录后进入控制台，左侧菜单找「API Keys」（有的版本叫「API 密钥」） 4. 点「创建 API Key」，名字随便填，比如 `nebula` 5. 复制生成的那一长串字符，**先存到手机备忘录** > ⚠️ 这串东西等于钱。**不要发给任何人，不要贴进网页输入框，不要提交 GitHub。** > 只填进服务器后台的「环境变量」里。 --- ## 第 2 步：部署后端到阿里云函数计算 FC（最麻烦的一步，约 20~30 分钟） ### 2.1 开通 1. 打开 2. 首次进入会提示开通「函数计算 FC」，点开通（选**按量付费**，不会扣钱，免费额度内） ### 2.2 创建函数 1. 左侧「函数」→「创建函数」 2. 选择 **「Web 函数」**（有的界面叫「使用示例创建」或「事件函数」，**优先选 Web 函数**） 3. 基本信息： - 函数名称：`nebula-ai-api` - 运行环境：**Node.js 20**（没有 20 就选 Node.js 18） - 内存：512 MB - 超时时间：**120 秒**（生图很慢，必须调大，默认 60 秒会失败） 4. 代码：选择「在线编辑」/「内置代码」，把 `server.js` 的**全部内容**粘进去 - 如果编辑器要求文件名，就用 `index.js` - 如果有「启动命令」输入框，填：`node index.js` ### 2.3 配置环境变量（最关键，漏了就 503） 在函数的「配置」→「环境变量」里新增三条： | 变量名 | 值 | |---|---| | `ZHIPU_API_KEY` | 第 1 步复制的 Key | | `STUDIO_ACCESS_CODE` | 你自己定一个访问码，比如 `nebula-2026`（别用生日、别用 123456） | | `PORT` | `9000` | ### 2.4 部署并拿地址 1. 点「部署代码」 2. 等状态变绿 3. 在「触发器」或「配置」页找 **公网访问地址 / 函数 URL**，形如： `https://xxx-xxx-xxx.cn-hangzhou.fcapp.run` 4. 复制这个地址 ### 2.5 立刻验证（不要跳过） 在浏览器地址栏直接打开：`你复制的地址 + /health` 应该看到类似： ```json {"ok":true,"service":"nebula-ai-api","aiConfigured":true,"accessCodeConfigured":true, "chatModel":"glm-4-flash","imageModel":"cogview-3-flash","dailyLimit":40} ``` - `aiConfigured: true` → Key 配对了 - `accessCodeConfigured: true` → 访问码配对了 - 两个都是 `false` → 环境变量没生效，回去 2.3 检查（改完要**重新部署**） > 想更彻底地确认 Key 能不能用，浏览器打开：`你的地址/self-test` 并带上访问码比较麻烦， > 直接在 `gen.html` 的「🔍 测试连接」里做就行——它会真的调一次模型，把智谱的原始报错显示出来。 --- ## 第 3 步：把新页面加到 GitHub（约 3 分钟） 1. 打开 2. 点右上「Add file」→「Create new file」 3. 文件名填：`gen.html` 4. 把 `gen.html` 的全部内容粘进大文本框 5. 拉到最下面点「Commit changes」 等 1~2 分钟，打开： --- ## 第 4 步：验证（3 次点击） 1. 「后端地址」粘贴第 2.4 步的地址 → 点 **🔍 测试连接** - 显示 `✅ 连接成功，服务端已就绪` → 后端通了 - 显示 `❌ 连不上` → 地址错了，或函数没启动 - 显示 `连接成功，但服务端还缺：…` → 环境变量没配好 2. 填访问码 3. 写一句描述：`一只穿宇航服的橘猫站在月球上` 4. 点「✨ 开始生成」，等 10~40 秒 --- ## 常见错误对照表 | 你看到的 | 原因 | 怎么办 | |---|---|---| | `Failed to fetch` | 根本连不上后端 | 检查地址是否以 `https://` 结尾、是否多了斜杠 | | `访问码不正确` | 访问码填错 | 和 `STUDIO_ACCESS_CODE` 逐字对齐 | | `服务端还没配置 AI 密钥` | 环境变量没生效 | 重新部署一次 | | `AI 服务返回错误：令牌已过期或验证不正确` | Key 复制错了/有空格 | 重新复制，注意别带空格 | | `AI 服务响应超时` | 函数超时时间太短 | 调到 120 秒 | | `今天的使用次数已用完` | 触发每日限流（默认 40 次） | 正常，明天恢复 | | `连接成功，但服务端还缺…` | 少配了环境变量 | 看 `/health` 里哪项是 false | --- ## 安全清单（必须做到） - [ ] Key 只存在服务器环境变量里，从未出现在 GitHub - [ ] 访问码只告诉信任的人，公开场合不提 - [ ] 网吧电脑用完：关浏览器、不留密码；访问码输入框刷新即清空 - [ ] 不在页面里写 `ZHIPU_API_KEY`（前端永远不该出现 Key） - [ ] 阿里云不升级付费套餐（免费额度够测试） --- ## 成本说明（诚实版，已更正） | 项目 | 费用 | |---|---| | 智谱 CogView-3-Flash 生图 | **免费** | | 智谱 GLM-4-Flash 聊天 | **免费** | | GitHub Pages 前端 | **0 元** | | 阿里云函数计算 | **新用户前 3 个月有免费额度；之后按量计费** | ⚠️ **重要更正**：函数计算不是"永久免费"。阿里云和腾讯云目前的政策都是**新用户前 3 个月**给免费额度（每月 100 万次调用 / 15 万 CU 之类），3 个月后按实际用量收费。 按你这个测试强度（每天几十次调用），3 个月后大概**每月几毛到几元**，不会失控。但要主动做两件事： 1. 阿里云控制台 → 费用中心 → **设置预算提醒**（比如 10 元），超过就发短信 2. 别开"自动续费"，别升级套餐 **适合验证产品，不适合免费对外开放给大量用户。** 真有用户了，再算正经的服务器账。
